# Annual Mark Prediction

A Machine Learning project that predicts students' annual marks based on their previous academic scores and extra classes attended.

## 📁 Repository Structure
- `jupyter.ipynb`: Data preprocessing, exploratory data analysis, and model training.
- `student_mark.csv`: Dataset containing student records.
- `student_annual_marks_model.pkl`: Saved machine learning model.
- `main.py`: Script to load the trained model and run predictions in Spyder/Python.
